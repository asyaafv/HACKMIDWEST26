Mode: Operate. User-approved, code-first implementation of a supplied reference. No concept invention or generated comps.

## Direction contract
THESIS: Review each transaction alongside its business reason, using the supplied authorization queue as fixed visual authority.

OWN-WORLD: Near-black cool surfaces, pale blue supporting text, white Inter headings, thin separators, compact status badges. Original character artwork cropped circularly; no substitute merchant imagery.

STORY: Scan queue, filter/search, inspect a selected request, follow evidence and policy checks, then record a local decision. Manage Gatekeepers and local rules in the same shell.

FIRST VIEWPORT: 1672×941 reference, 240px sidebar, 70px top bar, dense center table, 456px right detail panel. GitHub selected. Rainbow logo plus Gate at top left. Primary additions use pale neutral buttons. Below 1536px details become an overlay; below 1024px navigation collapses.

FORM: Supplied screenshot plus explicitly approved new-page layouts. Seed key: user-pinned-gate-reference. Signature interaction: selected table row synchronizes the evidence/detail panel, preserving the surrounding queue.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
